# Sedmica

Nedeljni jelovnik po tvom budžetu — weekly meal planner for Serbia.
FastAPI + SQLite backend, React/Vite frontend (SR/RU, light/dark).

- `backend/` — API + plan generator (recipes, RSD prices, budget fitting)
- `frontend/` — SPA (onboarding wizard, plan, day view, shopping list)
- `deploy/deploy.sh` — install/update on VPS (service on port 8102)
